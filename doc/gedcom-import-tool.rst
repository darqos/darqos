GEDCOM Import Tool
==================

GEDCOM is a standard file format for recording geaneology information.
It would make sense to be able to import family data as Person and
Place entities from GEDCOM files.

It might also make sense to export data in GEDCOM format, THe operator
could select a key person, and export their ancestors and descendants
in GEDCOM
format.

This tool should work like similar importers, matching existing
entities where it has high confidence that they're the same, and
making a queue of those that need manual clarification.
