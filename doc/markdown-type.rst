Markdown Type
=============

* Support GitHub-Flavoured Markdown format + embedded HTML

  * That ends up being a super-set of GFM and CommonMark
  * And should be compatible with Gruber/Schwarz Markdown

Type
----

* Standard entity base with storage blob to contain the text.

Lens
----

* Cyclable markup / side-by-side / rendered views

  * Default to rendered view
  * Hotkey to toggle edit mode
  * Edit mode defaults to markup view

* Syntax cheatsheet in online help
* Syntax highlighting in editor
* Possible parser?  https://github.com/Zopieux/pycmarkgfm
